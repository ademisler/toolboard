## EN

### Short Description
Toolboard combines 82 browser tools in one fast extension for inspection, capture, conversion, preview, and AI-assisted workflows.

### Detailed Description
Toolboard is an all-in-one Chrome extension for people who work on the web every day.

It includes 82 tools across:
- Inspect (7)
- Capture (6)
- Enhance (5)
- Utilities (5)
- Converters (31)
- Previewers (22)
- AI (6)

What you can do with Toolboard:
- Inspect page elements, links, fonts, accessibility signals, security headers, and Core Web Vitals.
- Capture screenshots, page text, media, PDFs, QR codes, and tab recordings.
- Convert common data, text, and media formats quickly for day-to-day browser tasks.
- Preview and validate structured content and metadata before publishing or sharing.
- Use AI tools for summarization, translation, content checks, SEO review, email drafting, and contextual chat.

Built for speed and daily usage:
- Fast popup search and category filters.
- Favorites and usage-based sorting.
- Clean dark/light theme support.
- English, Turkish, and French interface.
- AI provider flexibility: choose the provider that fits your workflow and switch without changing tools.

Privacy-first approach:
- Tools run when you activate them.
- Most processing happens locally in your browser.
- Data is not sold or used for tracking.
- AI features use your own configured API keys.

Toolboard helps developers, SEO specialists, QA teams, content teams, and power users reduce tab switching and finish browser tasks faster.

### What’s New (V3.0.0)
- Unified release versioning updated to V3.0.0.
- Multi-provider AI support added. Toolboard now supports Gemini, OpenAI, Anthropic, and additional OpenAI-compatible providers.
- Expanded and refined 82-tool workflow across inspect, capture, preview, converter, utilities, and AI categories.
- Improved UX flow, tool discoverability, and overall reliability.

## FR

### Description Courte
Toolboard réunit 82 outils dans une extension Chrome rapide pour l’inspection, la capture, la conversion, la prévisualisation et les workflows assistés par IA.

### Description Détaillée
Toolboard est une extension Chrome tout-en-un conçue pour les personnes qui travaillent sur le web au quotidien.

Elle inclut 82 outils dans les catégories suivantes :
- Inspection (7)
- Capture (6)
- Amélioration (5)
- Utilitaires (5)
- Convertisseurs (31)
- Prévisualisation (22)
- IA (6)

Ce que vous pouvez faire avec Toolboard :
- Inspecter les éléments d’une page, les liens, les polices, les signaux d’accessibilité, les en-têtes de sécurité et les Core Web Vitals.
- Capturer des écrans, du texte de page, des médias, des PDF, des QR codes et des enregistrements d’onglet.
- Convertir rapidement des formats courants de texte, de données et de médias pour les tâches web quotidiennes.
- Prévisualiser et valider des contenus structurés et des métadonnées avant publication ou partage.
- Utiliser des outils IA pour résumer, traduire, analyser du contenu, auditer le SEO, rédiger des e-mails et dialoguer avec contexte.

Pensé pour la vitesse et l’usage quotidien :
- Recherche rapide dans la fenêtre contextuelle et filtres par catégorie.
- Favoris et tri selon l’usage.
- Thèmes clair/sombre lisibles.
- Interface en anglais, turc et français.
- Flexibilité IA : choisissez le fournisseur adapté à votre flux de travail et changez de fournisseur sans changer d’outil.

Approche orientée confidentialité :
- Les outils s’exécutent uniquement quand vous les activez.
- La majorité du traitement se fait localement dans votre navigateur.
- Vos données ne sont ni vendues ni utilisées à des fins de suivi.
- Les fonctions IA utilisent vos propres clés API configurées.

Toolboard aide les développeurs, spécialistes SEO, équipes QA, équipes contenu et utilisateurs avancés à travailler plus vite dans le navigateur.
